## v1.7.0 — Lifecycle pill: separating "work item still open" from "process still running"

A focused minor release that introduces a **user-controlled Active/Closed pill** on every session row, decoupling whether the work item is wrapped up from whether the underlying Copilot CLI process is still alive. The dashboard sort and the default filter both updated to take advantage of the new signal.

### New

- **Lifecycle pill on every row.** A new chip rendered first in the row's chip strip shows `Active` (filled darker green) or `Closed` (transparent with a muted outline). Click it to toggle — the choice persists across restarts in `%LOCALAPPDATA%\CopilotSessionManager\lifecycle.json`. Closing a session's Copilot CLI process does *not* automatically mark it Closed: the lifecycle flag is yours to set, so a temporarily-closed session whose work item is still open stays Active and surfaces again on the next launch.
- **"Show closed" toolbar checkbox** (defaults to off). When checked, the dashboard also lists sessions you've marked Closed; when unchecked, they're hidden so the daily-driver view stays focused on in-flight work.
- **Per-theme `LifecycleActiveBrush`.** GitHub Dark `#238636`, GitHub Light `#116329`, Catppuccin Mocha `#40A02B`, Synthwave '80s `#1FB570`, High Contrast = system HighlightColor. Deliberately a deeper green than `SuccessBrush`/`StatusWorkingBrush` so the pill reads as its own marker, not as a status echo.

### Changed

- **Dashboard sort order is now Star → Active/Closed → Label → Updated.**
  - Starred sessions still pin to the top.
  - Within each star bucket, Active sessions come before Closed.
  - Within each Active/Closed bucket, sessions group by Label (enum order: Exploratory, Research, Feature, Bug, Refactor, Docs, Infra, Experiment).
  - Within each Label group, most-recently-updated first.
  - The old `StatusPriority` ordering (AwaitingApproval > Working > Idle > Orphaned > Inactive) is gone — process status no longer affects sort position. The user-controlled lifecycle is the primary axis.
- **Label change re-sorts the row** so a freshly-tagged session animates into its new label group.
- **"Show inactive" toolbar checkbox removed.** It was redundant with the new lifecycle filter (the underlying `ShowInactive` property is kept because the Merge Wizard still uses it).
